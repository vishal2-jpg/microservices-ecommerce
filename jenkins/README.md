
# Jenkins CI/CD Integration

## Project Overview
Jenkins is used to automate the build process
of the Microservices E-Commerce application.

## Microservices
- Eureka Server
- API Gateway
- Product Service
- User Service
- Order Service

## CI/CD Pipeline Objectives
1. Checkout source code from GitHub.
2. Build all Spring Boot microservices using Maven.
3. Execute automated tests.
4. Integrate GitHub with Jenkins.
5. Automate builds using GitHub webhooks.

## Tools
- Jenkins
- GitHub
- Git
- Java 17
- Maven
- Spring Boot
